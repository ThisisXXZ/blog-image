# Data structures and algorithms course figures

Lossless WebP figures for Lalande's Princeton Algorithms I / II and HKU COMP3251 notes.

This branch intentionally contains only this course's figures so its snapshot stays below jsDelivr's 50 MB GitHub package limit. Keep the full image library on main; add future course figures here without merging main's entire file tree.

The blog pins image URLs to an immutable commit. Original figures remain in the old-blog source archive; references are retained in the corresponding notes.
